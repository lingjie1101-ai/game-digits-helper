# 游戏数字随手贴 V3.5

迁移目标：D:\游戏数字随手贴。根目录的启动快捷方式指向 outputs\game-digits-v35\游戏数字随手贴 V3.5.exe。程序、配置、日志、完整包和开发资料均放在 D 盘。保留 EXE 同目录的 _internal 和 third_party。

第一次选择游戏窗口并连接。确认数字出现、“可以点击”亮绿时，直接在实际游戏里的确认输入框左键单击即可粘贴。仅该输入框触发；程序不移动鼠标，不点击确定。延续 V3.4 的两次预确认、新画面核对和数字变化时重新识别。

V3.5 新增：

- 自动记住标签、窗口标题与进程路径、识别参数、范围、小窗状态和暂停状态；重启只连接身份唯一匹配的窗口。同名或缺失窗口提示重新选择，不猜测目标。
- 显示“未连接 / 等待弹窗 / 正在识别 / 可以点击 / 正在粘贴 / 已暂停”状态。“全部暂停”和 Ctrl+Alt+P 切换全部暂停与恢复；只恢复暂停前正在运行的标签。
- “收进托盘”继续后台识别；右键托盘可显示窗口、暂停/恢复或退出。关闭窗口右上角 × 会真正退出。
- 重复启动会显示已有窗口，第二进程退出，不新开一套监听和识别服务。
- 按键发送在独立线程执行，界面保持响应；过程中再次操作鼠标或键盘、改变设置、切换游戏焦点、确认数字变化都会取消尚未发送的粘贴。Ctrl 始终配对释放。工具自己的模拟按键带标识，监听器只忽略自己的按键。
- 日志单文件最多约 1 MiB，保留 3 份历史，合计约 4 MiB；配置和日志均写在程序目录的 runtime。

默认 920×660，最小 800×600，小窗 380×600。各标签后台独立识别，普通复制以当前标签为准，点击粘贴按被点击的游戏窗口匹配。自动定位默认启用；手动位置是显式模式。尺寸变化后自动位置重新核对，手动位置停用并提示重新标记。

托盘复用 pystray 0.19.5 的官方 Windows 后端：
https://pystray.readthedocs.io/en/latest/usage.html
其他依赖继续使用 Umi-OCR、windows-capture、pynput、OpenCV、Pillow、NumPy、Tk；来源和许可见 THIRD_PARTY.txt 和 LICENSES。

OCR 在本机运行，服务仅监听 127.0.0.1:12255。VERIFICATION.txt 记录真实检查输出，HASHES.json 记录发布文件哈希。DIFF_FILE.patch 从本独立目录的空自定义基线重建源码及 EXE；在副本中使用 Git Bash 执行 ROLLBACK.sh 可验证回滚。用户 runtime 文件不放入公共压缩包；本机迁移会保留原配置与日志。
